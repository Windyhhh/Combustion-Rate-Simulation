### 1. **修复删除选中功能** ✅

**问题**: 删除选中按钮不能工作

**原因**: 代码使用了Treeview的API（`selection()`, `index()`），不适用于tksheet

**解决方案**: 使用tksheet的 `get_selected_rows()` 方法

**修改后的代码**:
```python
def delete_selected(self):
    """删除选中的工况"""
    # 获取tksheet选中的行
    selected_rows = self.case_sheet.get_selected_rows()
    
    if not selected_rows:
        messagebox.showinfo("提示", "请先选中要删除的工况")
        return
    
    # 确认删除
    count = len(selected_rows)
    result = messagebox.askyesno(
        "确认删除",
        f"确定要删除选中的 {count} 个工况吗？",
        icon="warning"
    )
    
    if not result:
        return
    
    # 从后往前删除，避免索引变化
    for row_idx in sorted(selected_rows, reverse=True):
        if 0 <= row_idx < len(self.cases):
            self.cases.pop(row_idx)
    
    self.refresh_view()
    self.update_statistics()
```

### 3. **解决表格额外蓝色列问题** ✅

**问题**: 表格右侧显示额外的蓝色空白列

**解决方案**: 固定左侧表格宽度，让右侧面板填充剩余空间

**实现方法**:
```python
# 左侧：工况列表表格（固定宽度450px）
left_panel = Frame(list_content, bg="#ffffff")
left_panel.pack(side=LEFT, fill=Y, padx=(0, 10))
left_panel.config(width=450)  # 固定宽度
left_panel.pack_propagate(False)  # 禁止子组件改变父组件大小

# 表格列宽总和 = 440px（小于450px）
self.case_sheet.column_width(column=0, width=80)   # 序号
self.case_sheet.column_width(column=1, width=180)  # 温度
self.case_sheet.column_width(column=2, width=180)  # 压力

# 右侧：信息面板（填充剩余空间）
right_panel = Frame(list_content, bg="#e8f4fd", relief="flat", bd=2)
right_panel.pack(side=RIGHT, fill=BOTH, expand=True, padx=(10, 0))
```

**效果**:
- ✅ 表格只显示3列，无额外空白列
- ✅ 表格宽度固定，视觉效果稳定
- ✅ 右侧面板占据剩余空间，充分利用界面
