## 📅 更新日期
2025-10-14

---

## 🎯 问题描述

### 用户反馈
> "步骤4删除选中部分，我希望是选择表格里面的一行的一个格，这一行就被删了，这样不需要把所有的删除，你现在点击一行的一格，显示请先选中要删除的工况，使得这个功能不能正常使用"

### 问题分析
1. **原有实现**: 只支持整行选择（`get_selected_rows()`）
2. **用户期望**: 点击表格中任意单元格，就能删除该行
3. **问题原因**: 当用户点击单个单元格时，`get_selected_rows()` 返回空列表，导致提示"请先选中要删除的工况"

---

## ✅ 解决方案

### 核心思路
使用多种方法获取选中的行号，支持：
1. **整行选择**: 用户点击行号或选中整行
2. **单元格选择**: 用户点击表格中的任意单元格
3. **多选**: 用户选中多个单元格或多行

### 实现代码

```python
def delete_selected(self):
    """删除选中的工况"""
    # 获取选中的行（支持整行选择和单元格选择）
    selected_rows = set()
    
    # 方法1: 获取选中的整行
    rows = self.case_sheet.get_selected_rows()
    if rows:
        selected_rows.update(rows)
    
    # 方法2: 获取选中的单元格，提取行号
    cells = self.case_sheet.get_selected_cells()
    if cells:
        for cell in cells:
            selected_rows.add(cell[0])  # cell = (row, col)
    
    # 方法3: 获取当前选中的位置
    current = self.case_sheet.get_currently_selected()
    if current:
        # current 可能是 (row, col) 或其他格式
        if isinstance(current, tuple) and len(current) >= 2:
            selected_rows.add(current[0])
    
    if not selected_rows:
        messagebox.showinfo("提示", "请先选中要删除的工况")
        return
    
    # 转换为列表并排序
    selected_rows = list(selected_rows)
    count = len(selected_rows)
    
    # 确认删除
    result = messagebox.askyesno(
        "确认删除",
        f"确定要删除选中的 {count} 个工况吗？",
        icon="warning"
    )
    
    if not result:
        return
    
    # 从后往前删除，避免索引变化
    for row_idx in sorted(selected_rows, reverse=True):
        if 0 <= row_idx < len(self.cases):
            self.cases.pop(row_idx)
    
    self.refresh_view()
    self.update_statistics()
    messagebox.showinfo("成功", f"已删除 {count} 个工况")
```

## 🔧 技术细节

### tksheet 选择API

#### 1. `get_selected_rows()`
- **返回**: 选中的整行行号列表
- **触发条件**: 用户点击行号或使用 `row_select` 绑定
- **示例**: `[0, 2, 5]` 表示选中了第0、2、5行

#### 2. `get_selected_cells()`
- **返回**: 选中的单元格坐标列表
- **格式**: `[(row, col), (row, col), ...]`
- **示例**: `[(0, 1), (0, 2), (1, 1)]` 表示选中了3个单元格

#### 3. `get_currently_selected()`
- **返回**: 当前焦点所在的位置
- **格式**: `(row, col)` 或其他格式
- **用途**: 获取当前光标位置

### 使用 `set()` 去重
由于可能同时从多个方法获取到同一行，使用 `set()` 自动去重：
```python
selected_rows = set()
selected_rows.update([0, 1, 2])  # 添加整行
selected_rows.add(1)  # 添加单元格所在行（自动去重）
# 结果: {0, 1, 2}
```

### 从后往前删除
避免删除时索引变化导致错误：
```python
for row_idx in sorted(selected_rows, reverse=True):
    self.cases.pop(row_idx)
```

**示例**:
- 删除第1、3、5行
- 如果从前往后删除：删除第1行后，原第3行变成第2行，原第5行变成第4行
- 从后往前删除：先删第5行，再删第3行，最后删第1行，索引不会错乱
