# 燃烧速度仿真软件 - 项目交付说明

## 📦 交付内容

### 1. 可执行文件
- **位置**: `dist/燃烧速度仿真软件.exe`
- **大小**: 22 MB
- **说明**: 独立可执行文件，无需安装Python环境，双击即可运行

### 2. 源代码文件
- **主程序**: `Gui.py` (74 KB)
- **核心模块**:
  - `Phase.py` - 相态计算模块
  - `Reactions.py` - 反应计算模块
  - `Species.py` - 物种数据模块
  - `delta_layer.py` - Delta层计算
  - `melt_layer.py` - 熔化层计算
  - `run.py` - 运行脚本

### 3. 资源文件
- **Logo图片**:
  - `logo1.png` (54 KB)
  - `logo2.jpg` (36 KB)
- **资源文件夹**: `resources/`
  - `chem.yaml` - 示例机理文件
  - `chem-liquid-phase-mechanism.txt`
  - `log-file-data-minima.txt`
- **动态链接库**: `lib/`
  - `hdf5.dll`
  - `hdf5_hl.dll`
  - `libifcoremd.dll`
  - `libmmd.dll`

### 4. 文档文件
- **README.md** - 详细说明文档（Markdown格式）
- **使用说明.txt** - 快速使用指南（文本格式）
- **项目交付说明.md** - 本文档
- **校正公式.txt** - 校正公式说明

### 5. 配置文件
- **requirements.txt** - Python依赖包列表
- **setup_conda_env.bat** - Conda环境设置脚本
- **启动软件.bat** - 快速启动脚本

### 6. 备份文件
- **备份文件/** - 所有旧版本GUI文件、文档、打包脚本
- **备用文件/** - 测试脚本和配置文件

## ✨ 主要特性

### 界面设计
1. **启动画面（4秒炫酷动画）**
   - 径向渐变背景
   - 60个浮动粒子系统
   - 粒子连接线（神经网络效果）
   - 虚线网格背景
   - 四角装饰（三层同心圆）
   - 边框装饰线
   - 三条扫描线动画
   - 双Logo发光卡片
   - 标题脉冲动画
   - 进度条动画

2. **主界面布局**
   - **左侧边栏（280px）**: 深蓝色科技风导航栏
     - 双Logo显示
     - 5个步骤导航按钮
     - 中英文双语显示
     - 鼠标悬停发光效果
     - 点击直接跳转
   
   - **顶部标题栏（100px）**: 蓝色渐变
     - 当前步骤信息（编号、标题、英文副标题）
     - 进度显示（步骤 X/5）
     - 系统状态指示器
   
   - **主内容区**: 浅蓝色背景
     - 带滚动条的大面积工作区
     - 网格背景装饰
     - 所有功能内容显示

### 核心功能
1. **步骤1：机理选择** 📁
   - 液相机理文件选择（.yaml）
   - 分子参数文件选择（.yaml）
   - 气相机理文件选择（.yaml）
   - 文件路径验证
   - 文件状态实时显示

2. **步骤2：配方设计** 🧪
   - 化学组分表格编辑
   - 含量和备注可编辑
   - 自动计算总含量
   - 含量验证（必须=100%）
   - 密度设置（默认1.60 g/cm³）
   - 添加/删除组分
   - 从机理文件自动读取组分

3. **步骤3：贮存参数** ⏱️
   - 贮存年限选择（0-50年）
   - 预设年限快捷按钮（0/5/10/20/30/50年）
   - 贮存时间说明

4. **步骤4：工况配置** 🌡️
   - 温度选择（-40°C到75°C）
   - 压力选择（0.1-10 MPa）
   - 工况列表显示
   - 添加/删除工况
   - 工况验证

5. **步骤5：结果输出** 📊
   - 运行仿真计算
   - 实时输出显示
   - 进度跟踪
   - 结果汇总
   - 停止计算功能
   - 多线程运行（不阻塞界面）

## 🔄 重新打包说明

如需重新打包EXE文件，请执行以下命令：

```bash
# 激活conda环境
conda activate combustion_sim

# 清理旧文件
rm -rf build/燃烧速度仿真软件 dist/燃烧速度仿真软件.exe

# 重新打包
pyinstaller --onefile --windowed --name "燃烧速度仿真软件" --add-data "logo1.png;." --add-data "logo2.jpg;." Gui.py

# 打包后的文件位于 dist/ 目录
```
