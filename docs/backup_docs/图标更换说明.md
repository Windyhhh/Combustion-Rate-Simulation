# 工况配置图标更换说明

## 🎯 问题与解决

**用户建议**: 
> "工况配置应该换一个和其他4个图标一样宽的图标"

**原因**: 
- "🌡️"（温度计）emoji宽度较宽
- 导致文字对齐问题
- 即使设置了固定宽度，视觉上仍不够统一

**解决方案**: 
- 更换为标准宽度的图标
- 选择语义相关且视觉统一的emoji

---

## ✅ 图标更换

### 修改内容

**修改前**: 🌡️ (温度计)
**修改后**: ⚙️ (齿轮)

### 代码变更

**位置**: `Gui.py` 第1954行

```python
# 修改前
{"icon": "🌡️", "title": "工况配置", "subtitle": "CONDITIONS"},

# 修改后
{"icon": "⚙️", "title": "工况配置", "subtitle": "CONDITIONS"},
```

## 🔧 如果需要更换其他图标

如果您想更换为其他图标，只需修改 `Gui.py` 第1950-1956行：

```python
steps = [
    {"icon": "📁", "title": "机理选择", "subtitle": "MECHANISM"},
    {"icon": "🧪", "title": "配方设计", "subtitle": "FORMULA"},
    {"icon": "⏱️", "title": "贮存参数", "subtitle": "STORAGE"},
    {"icon": "⚙️", "title": "工况配置", "subtitle": "CONDITIONS"},  # ← 修改这里
    {"icon": "📊", "title": "结果输出", "subtitle": "RESULTS"}
]
```

**建议选择标准宽度的emoji**:
- 📁 📂 📄 📝 📋 📊 📈 📉 (文档类)
- 🧪 🔬 ⚗️ (科学类)
- ⚙️ 🔧 🔨 ⚡ (工具类)
- ⏱️ ⏰ ⏲️ (时间类)

**避免使用较宽的emoji**:
- 🌡️ 🌤️ 🌦️ (天气类，通常较宽)
- 🎛️ 🎚️ (控制类，可能较宽)
