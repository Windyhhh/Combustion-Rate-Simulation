## 🚀 打包EXE步骤

### 方法一：使用打包脚本（推荐）

1. **双击运行** `打包.bat`
2. 等待打包完成
3. 可执行文件位于 `dist/燃烧速度仿真软件.exe`

### 方法二：手动打包

#### 步骤1：打开命令提示符（CMD）
- 按 `Win + R`
- 输入 `cmd`
- 回车

#### 步骤2：切换到项目目录
```cmd
cd C:\Users\32517\Desktop\BR
```

#### 步骤3：激活conda环境
```cmd
conda activate combustion_sim
```

#### 步骤4：运行PyInstaller
```cmd
pyinstaller 燃烧速度仿真软件.spec
```

#### 步骤5：等待打包完成
打包过程需要2-5分钟，请耐心等待。

#### 步骤6：查看输出
打包完成后，可执行文件位于：
```
dist\燃烧速度仿真软件.exe
```

## 📞 注意事项

### 打包环境要求

- **Python版本**: 3.9
- **Conda环境**: combustion_sim
- **PyInstaller版本**: 6.0.0

### 常见问题

**Q: 打包失败，提示找不到模块？**
A: 确保已激活 `combustion_sim` 环境，并安装了所有依赖：
```cmd
conda activate combustion_sim
pip install -r requirements.txt
```

**Q: 打包后运行报错？**
A: 检查 `lib/` 和 `resources/` 文件夹是否完整，确保所有DLL和机理文件都存在。

**Q: 打包时间过长？**
A: 正常情况下打包需要2-5分钟，请耐心等待。如果超过10分钟，可以尝试重新打包。
