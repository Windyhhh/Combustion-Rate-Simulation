def validate(self):
    """验证并保存"""
    self.app.state["storage_year"] = int(self.year_var.get())
    try:
        env_temp = float(self.env_temp_var.get())
        self.app.state["env_temp"] = env_temp

        return False

## 🎯 环境温度的作用

### 在代码中的使用

**run.py** 第66行:
```python
env_temp = config.get('environment_temp', Tinit)  # 没提供就默认等于 Tinit
```

### 说明
- **环境温度**: 推进剂贮存环境的温度
- **默认行为**: 如果不设置，默认等于工况温度（Tinit）
- **现在**: 用户可以在步骤三中设置独立的环境温度
- **单位转换**: GUI中输入°C，传递给仿真时自动转换为K

### 使用场景
- 推进剂在某个温度下贮存（如25°C）
- 然后在不同温度下测试燃烧速度（如-40°C到75°C）
- 环境温度影响贮存过程中的化学变化
