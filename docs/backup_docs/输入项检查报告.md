## 🔧 如需添加环境温度输入

如果您认为需要添加环境温度输入，可以在步骤三（贮存参数）中添加：

```python
# 在Step3Storage类中添加
env_temp_frame = Frame(self, bg="#ffffff", relief="flat", bd=2)
env_temp_frame.pack(fill=X, pady=12)

Label(env_temp_frame,
      text="环境温度 (°C)：",
      font=("Microsoft YaHei UI", 12, "bold"),
      bg="#ffffff", fg="#0066ff").pack(side=LEFT, padx=20)

self.env_temp_var = StringVar(value="25")
env_temp_entry = Entry(env_temp_frame,
                      textvariable=self.env_temp_var,
                      font=("Microsoft YaHei UI", 12),
                      bg="#b3d9ff", fg="#0066ff",
                      width=12, justify=CENTER)
env_temp_entry.pack(side=LEFT, padx=8)
```

但根据当前代码逻辑，环境温度默认等于初始温度（工况温度），这是合理的默认行为。
