# 步骤切换自动保存修复说明

## 📅 日期
2025-10-15

---

## 🐛 问题描述

### 用户反馈
> "配方不对，储存时间不对，前面选择的结果没有传入最后的计算"

### 问题分析

**现象**:
- 在步骤二填写配方和密度
- 在步骤三选择贮存时间
- 切换到步骤五运行计算
- 计算时使用的配方、密度、贮存时间都是默认值，不是用户设置的值

**根本原因**:
- `show_frame()` 方法只是切换显示，**没有调用前一个步骤的 `validate()` 方法**
- 用户点击侧边栏导航按钮直接切换步骤
- 当前步骤的数据没有保存到 `self.app.state`
- 导致后续步骤读取不到用户设置的数据

**代码位置**:
- `show_frame()` 方法（第2733-2757行）

---

## ✅ 解决方案

### 修改策略
在切换步骤前，先调用当前步骤的 `validate()` 方法保存数据。

---

### 修改 `show_frame()` 方法

**位置**: 第2733-2768行

**修改前**:
```python
def show_frame(self, frame_name):
    """显示指定框架"""
    frame = self.frames[frame_name]
    frame.tkraise()

    # 调用on_show回调
    if hasattr(frame, 'on_show'):
        frame.on_show()

    # 更新当前步骤
    if frame_name in self.step_names:
        self.current_step = self.step_names.index(frame_name)
        # ... 更新导航按钮状态
```

**修改后**:
```python
def show_frame(self, frame_name):
    """显示指定框架"""
    # 在切换前，先验证并保存当前步骤的数据
    if hasattr(self, 'current_step') and self.current_step < len(self.step_names):
        current_frame_name = self.step_names[self.current_step]
        current_frame = self.frames.get(current_frame_name)
        if current_frame and hasattr(current_frame, 'validate'):
            # 调用validate保存数据（不阻止切换）
            try:
                current_frame.validate()
            except:
                pass  # 即使验证失败也允许切换
    
    frame = self.frames[frame_name]
    frame.tkraise()

    # 调用on_show回调
    if hasattr(frame, 'on_show'):
        frame.on_show()

    # 更新当前步骤
    if frame_name in self.step_names:
        self.current_step = self.step_names.index(frame_name)
        # ... 更新导航按钮状态
```

**改动**:
- ✅ 在切换前获取当前步骤的框架
- ✅ 检查是否有 `validate()` 方法
- ✅ 调用 `validate()` 保存数据
- ✅ 使用 try-except 确保即使验证失败也允许切换

## 💡 技术要点

### 自动保存时机
1. **用户点击侧边栏导航按钮** → 触发 `show_frame()`
2. **切换前调用当前步骤的 `validate()`** → 保存数据
3. **然后切换显示** → 显示新步骤
4. **调用新步骤的 `on_show()`** → 恢复数据

### 错误处理
- 使用 `try-except` 捕获验证错误
- 即使验证失败也允许切换
- 不阻止用户操作流程

### 兼容性
- 检查 `hasattr(self, 'current_step')` - 确保属性存在
- 检查 `hasattr(current_frame, 'validate')` - 确保方法存在
- 向后兼容，不影响没有 `validate()` 方法的步骤
