### 问题1: 删除选中功能不能实现 ❌

**用户反馈**:
> "现在工况配置有问题，表格删除选中的功能不能实现"

**问题原因**:
- 代码从Treeview迁移到tksheet后，删除功能没有更新
- 旧代码使用 `self.case_view.selection()` 和 `self.case_view.index()` 方法
- 这些是Treeview的方法，不适用于tksheet

**旧代码** ❌:
```python
def delete_selected(self):
    """删除选中的工况"""
    sel = self.case_view.selection()  # ❌ Treeview方法
    if not sel:
        return
    idxs = sorted([self.case_view.index(iid) for iid in sel], reverse=True)  # ❌ Treeview方法
    for i in idxs:
        if 0 <= i < len(self.cases):
            self.cases.pop(i)
    self.refresh_view()
```

**新代码** ✅:
```python
def delete_selected(self):
    """删除选中的工况"""
    # 获取tksheet选中的行
    selected_rows = self.case_sheet.get_selected_rows()  # ✅ tksheet方法
    
    if not selected_rows:
        messagebox.showinfo("提示", "请先选中要删除的工况")
        return
    
    # 确认删除
    count = len(selected_rows)
    result = messagebox.askyesno(
        "确认删除",
        f"确定要删除选中的 {count} 个工况吗？",
        icon="warning"
    )
    
    if not result:
        return
    
    # 从后往前删除，避免索引变化
    for row_idx in sorted(selected_rows, reverse=True):
        if 0 <= row_idx < len(self.cases):
            self.cases.pop(row_idx)
    
    self.refresh_view()
    self.update_statistics()
```

**关键改进**:
1. ✅ 使用 `get_selected_rows()` 获取选中的行索引列表
2. ✅ 添加确认对话框，防止误删
3. ✅ 显示删除数量，更友好
4. ✅ 删除后更新统计信息

### 2. 工况统计 📊

#### 工况总数
- 大号数字显示（28号字体）
- 实时更新
- 蓝色高亮 `#0066ff`

#### 温度范围
- 显示最小值和最大值
- 格式: `25°C ~ 50°C`
- 单一温度时: `25°C`
- 未设置时: `未设置`

#### 压力范围
- 显示最小值和最大值
- 格式: `0.1 ~ 5 MPa`
- 单一压力时: `0.1 MPa`
- 未设置时: `未设置`

**实现代码**:
```python
def update_statistics(self):
    """更新右侧统计信息"""
    # 更新工况总数
    count = len(self.cases)
    self.case_count_label.config(text=str(count))
    
    if count == 0:
        self.temp_range_label.config(text="未设置")
        self.pres_range_label.config(text="未设置")
    else:
        # 计算温度范围
        temps = [case["T"] for case in self.cases]
        min_temp = min(temps)
        max_temp = max(temps)
        if min_temp == max_temp:
            temp_text = f"{min_temp}°C"
        else:
            temp_text = f"{min_temp}°C ~ {max_temp}°C"
        self.temp_range_label.config(text=temp_text)
        
        # 计算压力范围
        pressures = [case["P"] for case in self.cases]
        min_pres = min(pressures)
        max_pres = max(pressures)
        if min_pres == max_pres:
            pres_text = f"{min_pres} MPa"
        else:
            pres_text = f"{min_pres} ~ {max_pres} MPa"
        self.pres_range_label.config(text=pres_text)
```
