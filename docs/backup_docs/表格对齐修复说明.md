# 表格对齐修复说明

## 🎯 问题描述

**用户反馈**: "工况配置的字和其他列的字体不在同一个垂直线上，不美观"

**问题分析**: 
- Treeview表格的**表头（heading）**和**内容（column）**对齐方式不一致
- 表头默认是**左对齐**
- 内容设置了**居中对齐**
- 导致表头和内容不在同一垂直线上

---

## ✅ 解决方案

### 修复内容

为所有Treeview表格的**表头**添加居中对齐设置：

#### 1. 步骤二 - 配方设计表格
**位置**: `Gui.py` 第824行

**修改前**:
```python
self.tree.heading(col, text=col)
self.tree.column(col, width=width, anchor=CENTER)
```

**修改后**:
```python
self.tree.heading(col, text=col, anchor=CENTER)  # ← 添加 anchor=CENTER
self.tree.column(col, width=width, anchor=CENTER)
```

## 🔍 技术细节

### Treeview对齐设置

Tkinter的Treeview组件有两个独立的对齐设置：

1. **heading()** - 设置表头的对齐方式
   ```python
   tree.heading(column, text="列名", anchor=CENTER)
   ```

2. **column()** - 设置内容的对齐方式
   ```python
   tree.column(column, width=100, anchor=CENTER)
   ```

### anchor参数值
- `W` (West) - 左对齐
- `CENTER` - 居中对齐
- `E` (East) - 右对齐

### 默认值
- **heading**: 默认 `anchor=W` (左对齐)
- **column**: 默认 `anchor=W` (左对齐)
