# 导航按钮对齐优化说明

## 🎯 问题描述

**用户反馈**: 
> "界面中'机理选择''配方设计''贮存参数''结果输出'这几个模块里，中文标题、英文说明和图标在垂直方向没有对齐，比如图标与文字的垂直居中程度不一致，需要将所有模块的中文标题、英文说明、图标在垂直方向统一对齐，同时让'工况配置'的样式（包括文字颜色、布局逻辑）与其他模块保持一致。"

**问题分析**:
1. **垂直对齐问题**: 图标和文字使用`pack`布局，无法精确控制垂直居中
2. **布局不一致**: 不同按钮的图标和文字对齐方式不统一
3. **样式一致性**: 所有5个导航按钮应该使用完全相同的布局逻辑和样式

---

## ✅ 解决方案

### 核心改进：使用Grid布局替代Pack布局

**原因**: 
- `pack`布局难以精确控制垂直居中
- `grid`布局可以精确控制行列对齐
- `grid`的`rowspan`可以让图标跨越两行，实现完美垂直居中

### 新布局结构

```
┌─────────────────────────────────────┐
│  📁  │  机理选择                    │  ← row 0
│      │  MECHANISM                   │  ← row 1
└─────────────────────────────────────┘
   ↑         ↑
 图标      文字区域
(rowspan=2) (分两行)
```

---

## 🔧 技术实现

### 修改前（Pack布局）

```python
# 图标
icon_label = Label(btn_content, text=step["icon"], ...)
icon_label.pack(side=LEFT, padx=(0, 15))

# 文字框架
text_frame = Frame(btn_content, ...)
text_frame.pack(side=LEFT, fill=X, expand=True)

# 中文标题
title_label = Label(text_frame, text=step["title"], ...)
title_label.pack(fill=X)

# 英文副标题
subtitle_label = Label(text_frame, text=step["subtitle"], ...)
subtitle_label.pack(fill=X)
```

**问题**: 
- 图标和文字框架水平排列，但垂直位置不可控
- 文字框架内的两个标签垂直堆叠，但整体与图标的垂直居中不精确

---

### 修改后（Grid布局）

```python
# 配置grid权重
btn_content.grid_columnconfigure(1, weight=1)
btn_content.grid_rowconfigure(0, weight=1)

# 图标 - 跨越两行，自动垂直居中
icon_label = Label(btn_content, text=step["icon"], ...)
icon_label.grid(row=0, column=0, rowspan=2, padx=(0, 15), sticky="")

# 中文标题 - 第0行，靠下对齐
title_label = Label(btn_content, text=step["title"], ...)
title_label.grid(row=0, column=1, sticky="sw", pady=(0, 1))

# 英文副标题 - 第1行，靠上对齐
subtitle_label = Label(btn_content, text=step["subtitle"], ...)
subtitle_label.grid(row=1, column=1, sticky="nw", pady=(1, 0))
```

**优势**:
1. **图标垂直居中**: `rowspan=2`让图标跨越两行，`sticky=""`让它在垂直方向居中
2. **文字精确对齐**: 
   - 中文标题在第0行，`sticky="sw"`靠左下对齐
   - 英文副标题在第1行，`sticky="nw"`靠左上对齐
   - 两行文字紧密贴合（`pady=(0, 1)`和`pady=(1, 0)`）
3. **完美垂直居中**: 图标的中心线与两行文字的中间线对齐

## 🎨 Grid布局详解

### Grid参数说明

```python
icon_label.grid(
    row=0,           # 起始行
    column=0,        # 起始列
    rowspan=2,       # 跨越2行
    padx=(0, 15),    # 右侧留15像素间距
    sticky=""        # 不粘附任何边，自动居中
)

title_label.grid(
    row=0,           # 第0行
    column=1,        # 第1列
    sticky="sw",     # 粘附到左下角（South-West）
    pady=(0, 1)      # 下方留1像素间距
)

subtitle_label.grid(
    row=1,           # 第1行
    column=1,        # 第1列
    sticky="nw",     # 粘附到左上角（North-West）
    pady=(1, 0)      # 上方留1像素间距
)
```

### Sticky参数
- `n` (North) - 上
- `s` (South) - 下
- `w` (West) - 左
- `e` (East) - 右
- `""` (空) - 居中
- `"sw"` - 左下角
- `"nw"` - 左上角
