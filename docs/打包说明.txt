========================================
燃烧速度仿真软件 v2.0 - 打包说明
========================================

【完成的工作】

1. ✅ 化学名称选择功能
   - 双击"化学名称"列弹出选择对话框
   - 支持搜索功能（按名称或化学式）
   - 自动填充化学组成、备注、默认含量

2. ✅ 序号自动更新功能
   - 添加/删除化学组分时自动更新序号
   - 空行不显示序号

3. ✅ 批量添加工况功能
   - 多选温度和压力
   - 自动生成所有组合

4. ✅ 智能删除功能
   - 点击任意单元格即可删除该行
   - 支持多选批量删除

5. ✅ 工况统计面板
   - 实时显示工况总数、温度范围、压力范围

6. ✅ 工况保存问题修复
   - 修复添加工况后无法计算的问题
   - 所有工况操作立即保存到全局状态

【打包步骤】

方法一：使用一键打包脚本（推荐）
1. 双击运行 "一键打包.bat"
2. 等待打包完成（2-5分钟）
3. 可执行文件位于 dist\燃烧速度仿真软件.exe

方法二：手动打包
1. 打开命令提示符（CMD）
2. 切换到项目目录：
   cd C:\Users\32517\Desktop\BR
3. 激活conda环境：
   conda activate combustion_sim
4. 运行打包命令：
   pyinstaller 燃烧速度仿真软件.spec
5. 等待打包完成
6. 可执行文件位于 dist\燃烧速度仿真软件.exe
