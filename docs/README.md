# 燃烧速度仿真软件 - 侧边栏导航版

## 📋 软件简介

燃烧速度仿真软件是一款专业的推进剂燃烧速度计算系统，采用现代化侧边栏导航设计，集成了机理选择、配方设计、贮存参数、工况配置和结果输出等完整功能。

**开发单位**：
- 西安近代化学研究所
- 西北工业大学

**版本信息**：侧边栏导航版（最新版）

### 🔧 核心功能

#### 步骤1：机理选择 📁
- 液相机理文件选择（.yaml）
- 分子参数文件选择（.yaml）
- 气相机理文件选择（.yaml）
- 文件路径验证
- 文件状态实时显示

#### 步骤2：配方设计 🧪
- 化学组分表格编辑
- 含量和备注可编辑
- 自动计算总含量
- 含量验证（必须=100%）
- 密度设置（默认1.60 g/cm³）
- 添加/删除组分
- 从机理文件自动读取组分

#### 步骤3：贮存参数 ⏱️
- 贮存年限选择（0-50年）
- 预设年限快捷按钮（0/5/10/20/30/50年）
- 贮存时间说明

#### 步骤4：工况配置 🌡️
- 温度选择（-40°C到75°C）
- 压力选择（0.1-10 MPa）
- 工况列表显示
- 添加/删除工况
- 工况验证

#### 步骤5：结果输出 📊
- 运行仿真计算
- 实时输出显示
- 进度跟踪
- 结果汇总
- 停止计算功能
- 多线程运行（不阻塞界面）

## 🚀 使用方法

### 方法1：直接运行Python脚本（推荐开发调试）

```bash
# 激活conda环境
conda activate combustion_sim

# 运行程序
cd src/gui && python Gui.py
```

### 方法2：运行EXE文件（推荐最终用户）

```bash
# 直接双击运行
cd build && 燃烧速度仿真软件.exe
```

---

## 📦 打包为EXE

使用PyInstaller打包为独立可执行文件：

```bash
# 激活conda环境
conda activate combustion_sim

# 打包为单个EXE文件
cd config
pyinstaller --onefile --windowed --name "燃烧速度仿真软件" --icon=../assets/images/logo1.png ../src/gui/Gui.py

# 或使用spec文件（如果有）
pyinstaller 燃烧速度仿真软件.spec
```

打包后的文件位于 `../build/` 目录。

**注意**：
- 需要将 `../assets/images/logo1.png` 和 `../assets/images/logo2.jpg` 与EXE文件放在同一目录
- 如果使用外部机理文件，需要确保文件路径正确

## 🔧 环境要求

### Python环境
- Python 3.9
- tkinter（GUI框架）
- PIL/Pillow（图像处理）
- cantera（燃烧计算）
- numpy（数值计算）
- threading（多线程）

### Conda环境设置

```bash
# 创建环境
conda create -n combustion_sim python=3.9

# 激活环境
conda activate combustion_sim

# 安装依赖
pip install -r requirements.txt
```

## 💡 使用流程

1. **启动软件**
   - 观看4秒炫酷启动动画
   - 自动进入主界面

2. **步骤1：机理选择**
   - 点击"浏览"按钮选择液相机理文件
   - 选择分子参数文件
   - 选择气相机理文件
   - 确认所有文件状态为"✓ 已选择"

3. **步骤2：配方设计**
   - 查看从机理文件读取的化学组分
   - 编辑各组分含量（确保总和=100%）
   - 设置密度（默认1.60 g/cm³）
   - 可添加/删除组分

4. **步骤3：贮存参数**
   - 选择贮存年限（0-50年）
   - 可使用快捷按钮

5. **步骤4：工况配置**
   - 设置温度（-40°C到75°C）
   - 设置压力（0.1-10 MPa）
   - 点击"添加工况"
   - 可添加多个工况

6. **步骤5：结果输出**
   - 点击"🚀 开始计算"
   - 实时查看计算输出
   - 查看结果汇总
   - 可随时停止计算
